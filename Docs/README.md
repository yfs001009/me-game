## 📖 文档使用指南

### 我是新加入的开发者
1. 阅读 [版本路线图](ROADMAP.md) 了解项目目标
2. 阅读 [游戏设计](GAME_DESIGN.md) 理解玩法
3. 阅读 [技术架构](ARCHITECTURE.md) 了解技术栈
4. 查看 [当前冲刺](CURRENT_SPRINT.md) 看看能帮什么忙

### 我想知道接下来做什么
1. 查看 [当前冲刺](CURRENT_SPRINT.md) 的任务清单
2. 查看 [待办清单](BACKLOG.md) 找到详细的子任务

### 我想了解某个技术细节
1. 查看 [Technical/](Technical/) 目录下的对应文档

### 我想添加新任务
1. 在 [待办清单](BACKLOG.md) 中添加任务
2. 如果是本周要做的，同步到 [当前冲刺](CURRENT_SPRINT.md)
